# Raphael7

*Raphael7* (as in HL7): heals messy real-world HL7 v2 feeds into clean FHIR.

A Python command-line tool that scans a real HL7 v2 message feed, finds the variations and outliers, turns chosen messages into regression tests, and checks the HL7 v2 → FHIR R4 (IL Core) output. It runs locally, so patient data never leaves the customer's network.

**Status:** in development, month 1 (Nov 23 – Dec 20, 2026).
