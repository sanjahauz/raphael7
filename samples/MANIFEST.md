# Sample corpus manifest

Generated by `scripts/make_samples.py` (fixed seed). Do not edit the files by hand:
change the generator and run `uv run python scripts/make_samples.py`.
`tests/test_samples.py` fails when the committed files and the generator disagree.

**Everything is made up.** Names, addresses, phone numbers, MRNs, visit numbers
and facilities are invented. Each teudat zehut (Israeli ID) is generated with a
*wrong* check digit, so it cannot be anyone's real ID; a test checks this.
The one exception is the placeholder `000000000`, which passes the check digit
but means "unknown": matching patients on it would merge different people.

## What each vendor sends

60 messages per vendor: 12 admissions (A01), 9 updates (A08), 9 discharges (A03),
10 CBC orders (ORM^O01) and 20 results (ORU^R01, CBC and BMP).

| | Vendor A `ADMITPRO` | Vendor B `MEDIX` | Vendor C `OLDHIS` |
|---|---|---|---|
| Version (MSH-12) | 2.5 | 2.3.1, but every 7th message says 2.5 (drift) | 2.4 |
| MSH-9 | `ADT^A01^ADT_A01` | `ADT^A01` (no structure) | `ADT^A01^ADT_A01` |
| Terminator | `\r` | `\n` (→ `terminator` warning) | `\r` |
| Delimiters (MSH-2) | `^~\&` | `^~\&` | `^!\&` (repetition is `!`) |
| Charset (MSH-18) | ASCII, not sent | UTF-8, `UNICODE UTF-8` | ISO-8859-8, `8859/8` |
| Names | Latin transliteration | Hebrew | Hebrew |
| Files | one message per file | one message per file | ADT/ORM: one MLLP-framed message per file; ORU: one batch file (FHS/BHS…BTS/FTS) per day |
| Timestamps | minutes | seconds | minutes |
| National ID | PID-3, first repeat (MRN second) | PID-2 on 2.3.1; PID-3 on 2.5 | PID-3, first repeat |
| ID problems | 2 of 12 patients have no national ID | 3 of 12 patients share the placeholder `000000000` | 1 patient has 20 PID-3 repeats (IDs from 18 older systems) |
| Visit number | PV1-19 | PID-18 | PV1-19 |
| HMO (kupat holim) | IN1-3 / IN1-4, letter codes | Z-segment `ZPI`, number codes | PV1-20, number codes |
| EVN-1 | filled | empty | filled |
| PV1 | always | always | missing in A08 and in ORU |
| Ordering provider | ORC-12 and OBR-16 | OBR-16 only | ORC-12 and OBR-16 |
| ORU | ORC, OBR, OBX | no ORC; NTE comment on BMP (with an escaped `\T\`) | ORC, OBR, OBX + one TX OBX whose OBX-5 has 3 repeats |
| Lab codes | LOINC | local codes only (`GLU^GLU^L`) | LOINC with the local code as alternate |
| OBX-8 when normal | `N` | empty | empty |

## Broken messages (`broken/`)

Made from one vendor A ORU (and one vendor C batch). The codes are the
`ParseIssue` codes the parser must report; `scan` must flag the ones with no
code by their shape.

| File | What is wrong | Expected codes |
|---|---|---|
| `empty.hl7` | empty file | `empty` |
| `no-msh.hl7` | MSH line missing | `no-msh`, `text-before-msh` |
| `bad-encoding.hl7` | MSH-2 `^~\&^` repeats a delimiter | `bad-encoding` |
| `short-encoding.hl7` | MSH-2 is only `^~` | `short-encoding` |
| `bad-segment-id.hl7` | `Pid` instead of `PID` | `bad-segment-id` |
| `bad-escape.hl7` | NTE with a Windows path `C:\lab\reports\2026` | `bad-escape` |
| `mixed-terminators.hl7` | `\r` after MSH, `\r\n` after the rest | `mixed-terminators` |
| `mllp-unbalanced.hl7` | MLLP start character without end | `mllp` |
| `windows-1255-no-charset.hl7` | Hebrew saved as Windows-1255, no MSH-18 | `decode` |
| `batch-count.hl7` | BTS-1 says one message more than the batch holds | `batch-count` |
| `unescaped-delimiter.hl7` | NTE text with a raw `&` and `\|` | none: an extra field and subcomponent |
| `truncated.hl7` | file cut two-thirds of the way, mid-segment | none: missing segments and fields |
